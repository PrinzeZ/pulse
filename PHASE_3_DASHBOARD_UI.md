# Phase 3 Dashboard UI

Added role-specific, scoped dashboards for:

- State Administrator — statewide hospital and inventory visibility
- District Administrator — district-scoped hospital and inventory visibility
- Hospital Administrator — hospital-scoped inventory, alerts, team and activity

The dashboards reuse the existing P.U.L.S.E clinical UI language and do not add a new frontend framework.

Session scope IDs are populated at login from the authenticated User entity.

No database schema changes are included in this UI update.
